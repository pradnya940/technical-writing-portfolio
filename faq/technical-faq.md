# Technical Writing and Python FAQ

## What is technical documentation?

Technical documentation explains how a product, system, or process works and how users can use it.

## What is Markdown?

Markdown is a lightweight markup language used to format text using headings, lists, links, code blocks, and other elements.

## What is a README file?

A README introduces a project, explains its purpose, describes how to use it, and provides important setup information.

## What is Generative AI?

Generative AI refers to AI systems that can create content such as text, code, images, and summaries based on user input.

## What is an AI hallucination?

An AI hallucination occurs when an AI system produces information that is incorrect or unsupported but presents it as if it were true.

## Why should AI-generated documentation be reviewed?

Human review helps identify factual errors, missing steps, unclear instructions, and unsupported claims.

## What is GitHub?

GitHub is a platform for hosting Git repositories, managing project files, tracking changes, and collaborating on software and documentation.
